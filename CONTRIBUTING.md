# Contributing

This repository is **mirrored from GitLab** by Connectix CI. Every file in it is generated or copied
from the private source repository on each `docs-v*` tag, and the next tag overwrites the whole tree.

- **Pull requests are not accepted** - they would be lost on the next publish, and the repository's
  ruleset blocks merges from anyone but the CI account.
- Found a mistake in the skill, a guide, an endpoint page or the OpenAPI spec? **Open an issue** at
  https://github.com/connectix-bg/ai/issues with the file name and the fix you expect. Docs issues are
  triaged with the API backlog and ship with the next docs tag.
- Security reports: see https://connectix.bg/security or e-mail security@connectix.bg; do not open a
  public issue.

Thank you for reading the docs closely enough to find something.
